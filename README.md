## Simple recommendation by level

- **Beginner:** ISC2 CC, Security+
- **Intermediate blue team:** CySA+, AZ-500
- **Offensive security:** CEH, OSCP
- **Senior / architecture / management:** CISSP
- **Premium but expensive foundation:** GSEC

## Quick advice

If you are just starting, the best value path is usually:

1. **ISC2 CC** or **Security+**
2. **CySA+** or **AZ-500** depending on whether you want SOC or cloud security
3. **OSCP** if you want pentesting
4. **CISSP** later for senior roles
